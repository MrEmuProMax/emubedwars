# emubedwars - 3D Minecraft Bed Wars

👉 **[點擊這裡立刻在瀏覽器遊玩：Minecraft 網頁版 3D 空島床戰](https://emubedwars.vercel.app)**

## 🎮 遊戲簡介 / Introduction
這是一款基於 HTML5 與 Three.js 技術開發的 3D Minecraft 網頁版線上遊戲。玩家不需要下載任何麥塊客戶端，直接展開激烈的空島床戰（Bed Wars）！

## 🚀 技術棧 / Tech Stack
* **Frontend:** Vanilla HTML5, Tailwind CSS
* **3D Engine:** Three.js
* **Multiplayer:** PeerJS (WebRTC P2P 多人連線)
* **Hosting:** Vercel
